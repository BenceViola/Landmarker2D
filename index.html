One landmark per line: LM01 | Name | description | pair=LM02. Curves: curve C01 | Name | start=LM02 end=LM03 n=10 path=spline (add closed for loops; path is polyline or spline). Lines starting with # set the id, name and version. List order is export order. Ids never change once data exists; names can.
